# Title

One line summarizing the change.

## Requested by

Name / handle / email.

## Type

One of: copy, style/design, new-feature, bugfix, integration, content, other.

## Description

What do you want changed, and why? Be as concrete as possible — "make the CTA button orange" is easier to act on than "improve the button."

## Context an implementer will need

Anything that isn't obvious from the description alone:
- Design references (screenshots, links, exact hex codes)
- For an integration: the API contract (endpoint, auth method, request/response shape), sandbox vs. prod credentials, rate limits
- Specific pages/sections affected
- Anything explicitly out of scope

## Acceptance criteria

How would you verify this is done? A short checklist is ideal, e.g.:
- [ ] Button color changes to `#E07A3E` on hover
- [ ] No layout shift on mobile
